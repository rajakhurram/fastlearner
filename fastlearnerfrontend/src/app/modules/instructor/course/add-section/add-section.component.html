Read Instructions

Use the sample Excel template to add many quiz questions at once. Each row is one question.

  • Download the sample template from the upload window, fill in your questions, then upload the completed .xlsx file.
  • Step 1 (required): Upload your Excel file and click Import.
  • Step 2 (optional): If your Excel uses image file names, upload a single image or a .zip of images first.
  • Required Excel columns: questionText, questionType, explanation, questionImageUrl, A–F, correctAnswers.
  • Allowed questionType values: SINGLE_CHOICE, MULTIPLE_CHOICE, TRUE_FALSE, TEXT_FIELD.

For a question image, put only the file name in questionImageUrl column (e.g. diagram.png).

For option images, put the file name in A–F; use plain text for text options.

For TEXT_FIELD, put the expected answer in correctAnswers; options can stay empty.

For correct answers: options map to A, B, C, D, E, F Single choice: one letter (e.g. B). Multiple choice: comma-separated letters (e.g. A,C).

For one image: upload that image file only. Many images: upload a .zip; image file names must match the images name in Excel.

Only .xlsx files are supported. Text-only questions do not need image upload.
